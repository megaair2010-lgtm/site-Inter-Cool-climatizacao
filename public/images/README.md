# Fotos do site

Coloque aqui fotos **reais** da empresa (equipe, obras, equipamentos instalados) e informe
os caminhos em `src/config/site.ts` → `IMAGES`, e em `src/data/content.ts` (projetos e antes/depois).

- Formato: `.webp` ou `.jpg`, até ~300 KB cada (largura 1600 px para a foto principal, 1000 px para cards).
- Use apenas fotos com autorização do cliente/local.
- Enquanto não houver foto, o site mostra o aviso "Espaço para foto real".
